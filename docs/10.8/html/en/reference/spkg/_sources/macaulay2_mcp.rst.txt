macaulay2_mcp: MCP server for Macaulay2: Groebner bases, resolutions, Betti tables, and more
============================================================================================

Description
-----------

MCP server for Macaulay2: Groebner bases, resolutions, Betti tables, and more, for
Claude Code, opencode, and any MCP client

License
-------

GPLv3

Upstream Contact
----------------

https://pypi.org/project/macaulay2-mcp/



Type
----

optional


Dependencies
------------

- $(PYTHON)
- $(PYTHON_TOOLCHAIN)
- :ref:`spkg_sagemath_macaulay2`

Version Information
-------------------

requirements.txt::

    macaulay2-mcp

Installation commands
---------------------

.. tab:: PyPI:

   .. CODE-BLOCK:: bash

       $ pip install macaulay2-mcp

.. tab:: Sage distribution:

   .. CODE-BLOCK:: bash

       $ sage -i macaulay2_mcp


However, these system packages will not be used for building Sage
because ``spkg-configure.m4`` has not been written for this package;
see :issue:`27330` for more information.
