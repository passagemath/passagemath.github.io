mathics3_jupyter_kernel: Jupyter Notebook integration for Mathics3
==================================================================

Description
-----------

Jupyter Notebook integration for Mathics3

License
-------

Upstream Contact
----------------

https://pypi.org/project/mathics3-jupyter-kernel/



Type
----

optional


Dependencies
------------

- $(PYTHON)
- $(PYTHON_TOOLCHAIN)
- :ref:`spkg_jupyterlab`
- :ref:`spkg_mathics3`

Version Information
-------------------

requirements.txt::

    mathics3-jupyter-kernel

Installation commands
---------------------

.. tab:: PyPI:

   .. CODE-BLOCK:: bash

       $ pip install mathics3-jupyter-kernel

.. tab:: Sage distribution:

   .. CODE-BLOCK:: bash

       $ sage -i mathics3_jupyter_kernel


However, these system packages will not be used for building Sage
because ``spkg-configure.m4`` has not been written for this package;
see :issue:`27330` for more information.
