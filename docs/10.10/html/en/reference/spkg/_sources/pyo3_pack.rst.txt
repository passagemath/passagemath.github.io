.. _spkg_pyo3_pack:

pyo3_pack: Build and publish crates with pyo3, rust-cpython and cffi bindings as well as rust binaries as python packages
=========================================================================================================================

Description
-----------

Build and publish crates with pyo3, rust-cpython and cffi bindings as well as rust binaries as python packages

License
-------

MIT OR Apache-2.0

Upstream Contact
----------------

https://pypi.org/project/pyo3-pack/



Type
----

optional


Dependencies
------------

- $(PYTHON)
- :ref:`spkg_pip`

Version Information
-------------------

package-version.txt::

    0.6.1

version_requirements.txt::

    pyo3-pack

Installation commands
---------------------

.. tab:: PyPI:

   .. CODE-BLOCK:: bash

       $ pip install pyo3-pack

.. tab:: Sage distribution:

   .. CODE-BLOCK:: bash

       $ sage -i pyo3_pack


However, these system packages will not be used for building Sage
because ``spkg-configure.m4`` has not been written for this package;
see :issue:`27330` for more information.
