.. _spkg_libpoly:

libpoly: Library for manipulating polynomials
=============================================

Description
-----------

SRI LibPoly is a C library for manipulating polynomials that is popular
in the domain of Satisfiability Modulo Theories.

License
-------

LGPL 3.0

Upstream Contact
----------------

https://github.com/SRI-CSL/libpoly


Type
----

optional


Dependencies
------------

- $(MP_LIBRARY)
- :ref:`spkg_cmake`
- :ref:`spkg_ninja_build`

Version Information
-------------------

package-version.txt::

    0.2.1

Installation commands
---------------------

.. tab:: Sage distribution:

   .. CODE-BLOCK:: bash

       $ sage -i libpoly


However, these system packages will not be used for building Sage
because ``spkg-configure.m4`` has not been written for this package;
see :issue:`27330` for more information.
